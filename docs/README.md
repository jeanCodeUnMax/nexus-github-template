# 📚 Documentation NEXUS Template

Bienvenue ! Ce guide explique **comment utiliser le template NEXUS** pour automatiser votre gestion de projet, avec un système Kanban et des agents intelligents.

## 🎯 Vue d'ensemble (pour débutants)

Le template NEXUS automatise votre flux de travail GitHub en 3 étapes :

1. **Idée → Epic** : Vous décrivez une idée dans une issue
2. **Epic → Tasks** : Les agents ou vous décomposez en sous-tâches
3. **Tasks → PR & Done** : Chaque tâche devient une PR, le Kanban se met à jour automatiquement
